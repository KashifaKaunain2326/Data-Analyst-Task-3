# Data-Analyst-Task-3
Task 3: SQL for Data Analysis

📌 Project Overview

This project focuses on using SQL queries to extract, manipulate, and analyze structured data from a database.

The objective is to perform data analysis using SQL and gain practical experience with database operations and query optimization.

🎯 Objectives

- Retrieve data using SELECT statements.
- Filter records using WHERE.
- Sort data using ORDER BY.
- Group data using GROUP BY.
- Perform JOIN operations.
- Write subqueries for data analysis.
- Use aggregate functions such as SUM() and AVG().
- Create views for analysis.
- Optimize queries using indexes.

🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

📂 Dataset

E-commerce SQL Database

The dataset is used to perform SQL queries and analyze business-related information.

📊 Tasks Performed

1. SELECT, WHERE and ORDER BY queries.
2. GROUP BY and aggregate functions.
3. INNER JOIN, LEFT JOIN and RIGHT JOIN.
4. Subqueries for advanced data analysis.
5. SUM() and AVG() functions.
6. Creating SQL views.
7. Creating indexes for query optimization.

📁 Project Deliverables

- SQL query file.
- Screenshots of SQL queries and their outputs.
- README.md file explaining the project.

📈 Learning Outcomes

- Improved SQL querying skills.
- Understanding of relational databases.
- Practical experience with JOINs and subqueries.
- Ability to perform data analysis using SQL.
- Understanding of views and query optimization.
